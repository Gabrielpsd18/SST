##### Trabajadores

# Objetivo
Administrar la información de los trabajadores de la empresa.

# Información principal
- Tipo de documento
- Número de documento
- Nombre completo
- Cargo
- Área
- Sede
- Correo corporativo
- Teléfono

# Información adicional
- Fecha de nacimiento
- Sexo
- Correo personal
- País
- Departamento
- Provincia
- Distrito
- Dirección

# Relaciones
- Capacitaciones
- EMOs
- EPP
- RACs
- Inspecciones
- Accidentes / Incidentes
- Observaciones que se le deje al Trabajador (Notas)
