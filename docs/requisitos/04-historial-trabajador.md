
##### RAC (Reporte de Acción Correctiva)

# Objetivo

Permitir que un trabajador registre una acción de mejora o corrección realizada para reducir un riesgo o mejorar las condiciones de seguridad.


##### Inspecciones

# Objetivo
Registrar inspecciones de seguridad y realizar seguimiento de los hallazgos encontrados.

# Información general

- Código
- Área
- Responsable (El que programo la inspeccion)
- Fecha programada
- Fecha de ejecución
- Estado
- Resultado

# Datos de planificación

- Tipo de inspección
- Planeada / No planeada
- Razón social
- Sede
- Área o lugar
- Grupo (Varios responsables que iran o uno solo)
- Objetivo
- Formulario utilizado

# Desarrollo

Durante la inspección se debe registrar:

- Observaciones
- Fotografías
- Evidencias

# Seguimiento

Cada inspección puede generar:

- Hallazgos
- Acciones correctivas
- Estado de cumplimiento

# Relaciones

- Trabajadores
- Formularios (El formulario en si es casi el seguimiento de lo que se realizó o se realizará)
- Acciones Correctivas
- Evidencias
