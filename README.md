# SST - Sistema de Seguridad y Salud en el Trabajo

## Descripción

Sistema para la gestión de Seguridad y Salud en el Trabajo, orientado al registro de incidentes, inspecciones, capacitaciones, gestión documental y generación de reportes.

## Objetivos

- Digitalizar los procesos SST.
- Centralizar la información.
- Facilitar la toma de decisiones mediante indicadores.
